About

3D HiC Viewer

A browser-based viewer for reconstructing and exploring the three-dimensional structure of chromosomes from Hi-C contact matrices.

Developed by Prof. Wang's team · lab.szu-bioinf.org

Project on GitHub Source code · pure-frontend branch ↗

What it does

  1. Sparse contacts — reads a normalized Hi-C matrix (i  j  contact), tab / comma / whitespace separated.
  2. Full matrix — a log10(x+1) transform and symmetrisation produce the complete n×n contact matrix.
  3. Distances — bins become graph nodes, contacts become edges weighted 1/contact, and all-pairs shortest paths give the distance matrix.
  4. 3D coordinates — classical multidimensional scaling returns an n×3 point cloud.

The result is rendered with three.js: a colour-coded chromatin chain you can rotate, zoom and pan, with adjustable smoothing, line width and node markers. Export it as a PNG, a vector SVG, a rotation video, or the raw coordinates and matrix as CSV.

Everything runs locally

There is no server-side computation: your contact matrix never leaves the browser. The pipeline runs in a Web Worker, and the viewer uses the same dependency-free core module as the bundled command-line tools.

Credits

  • Algorithm — ShRec3D, from 3D genome reconstruction from chromosomal contacts (Nature Methods, 2014).
  • Reference implementation — kpj/ShRec3D .

Input format

The viewer reads a sparse Hi-C contact matrix: one contact per line, three columns. 

# i    j      contact
0      0      7047.9995
0      1000   3535.2393
1000   1000   6878.4727
0      2000   1.7134484
1000   2000   3649.68
Column Meaning
i Position of the first bin (bp).
j Position of the second bin (bp). Same units as i.
contact Normalized contact value for that pair — how often the two loci were found close together. Non-negative; larger means closer.

Syntax rules

  • Separator — tab, comma, semicolon or any run of whitespace, mixed freely. The sample files are tab-separated.
  • Extra columns are ignored; only the first three are read.
  • Blank lines and lines starting with # are skipped.
  • Either triangle is fine — (i, j) and (j, i) are merged, duplicates are averaged, and the diagonal holds the self-contacts.
  • File types — .metrics, .tsv, .txt, .csv, .mat, .dat all work; the picker just filters by extension, dropping a file always works.

How it is used

  • Contacts are transformed with log10(x+1) and completed into a full n×n symmetric matrix.
  • A contact of 0 means “no evidence of contact” — the pair is left unconstrained rather than pulled together.
  • The bin positions become the labels of the resulting matrix and the coordinates, so keep them in consistent units (the sample uses 1000 bp bins: 0, 1000, 2000, …).

A line with fewer than three columns, or with a value that is not a number, stops the run and reports the offending line number.
